Get live NSE data — one-time setup

Websites can't read nseindia.com directly, so a bookmark fetches the option chain from an NSE tab using your own browser session, and hands it to this page.

  1. Drag this button to your bookmarks bar (or right-click → Bookmark link): 📈 F&O → Dashboard
  2. Open nseindia.com/option-chain and let it load.
  3. Click the bookmark on that page. This dashboard opens connected to the NSE tab — pick a symbol and expiry, press Analyze, or turn on auto-refresh. Keep the NSE tab open.

Desktop Chrome, Edge, Firefox or Safari. Allow pop-ups for nseindia.com if asked. If the tabs can't be linked, the bookmark downloads the chain as a file instead — upload it with “Upload saved NSE JSON”.
